🔐 AUTHENTICATION FLOW

1. User enters credentials on LoginScreen
2. App sends to Django: POST /api/auth/login/
3. Django returns: { token, user }
4. App saves token in AsyncStorage
5. All requests auto-inject token header
6. On logout: POST /api/auth/logout/ & clear token

🐛 TROUBLESHOOTING

Error: "Cannot find module"
   Fix: npm install

Error: "Cannot connect to Django"
   Fix: 
   1. Verify Django running: curl http://127.0.0.1:8000
   2. Update API_BASE_URL in api/client.ts
   3. Check CORS settings in Django

Error: "Port in use"
   Fix: npx expo start --clear

Error: "Module resolution failed"
   Fix: 
   rm -rf node_modules package-lock.json
   npm install
